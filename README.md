## 📖 Git Commands Reference

| Perintah | Fungsi |
|---|---|
| `git init` | Membuat repository pada folder lokal (muncul folder `.git`) |
| `git status` | Mengetahui status repository lokal |
| `git add` | Menambahkan berkas ke staging area |
| `git commit` | Menyimpan perubahan ke repository lokal (belum ke remote) |
| `git push` | Mengirim perubahan hasil commit ke remote repository |
| `git branch` | Melihat seluruh branch pada repository |
| `git checkout` | Berpindah ke branch yang dipilih |
| `git merge` | Menggabungkan branch aktif dengan branch yang dipilih |
| `git clone` | Membuat salinan repository |
| `git pull` | Mengambil dan menggabungkan perubahan dari remote |
| `git fetch` | Mengambil perubahan dari remote tanpa menggabungkan |
